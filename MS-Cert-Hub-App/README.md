# MS Cert Hub App

This is a React web application representing the **MS Cert Hub - Microsoft Certifications Learning Portal**. It was scaffolded using Vite and styled with Tailwind CSS.

## Overview
This application serves as a learning portal for Microsoft Certifications like PL-900, PL-400, PL-500, and MB-500. It tracks course modules, progress, and certification metadata.

## Run Locally
To run the project locally:

```bash
# Install dependencies
npm install

# Start the dev server
npm run dev
```

## Build
```bash
npm run build
```
